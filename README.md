# File Format Converter

**File Format Converter** is a desktop application that allows you to convert files between different formats, for example:
- **TXT ↔ PDF**
- **PNG ↔ JPG**

With this application, you can:
- Drag and drop files for quick conversion
- Easily select the format for conversion
- Get status updates and a progress bar while the conversion is running

## Technologies

- **Programming Language**: C#
- **Framework**: .NET 6 (or 7)
- **GUI**: WPF (Windows Presentation Foundation)
- **Main Libraries**:
  - **iText 7** for PDF handling
  - **SixLabors.ImageSharp** for image processing
